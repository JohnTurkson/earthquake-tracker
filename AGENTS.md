# Project requirements

Read [README.md](README.md) before planning or changing this project. It defines
USGS Tracker's high-level product requirements. Keep the app Android-only and use
these requirements to guide design, implementation, and testing.

# Formatting

- Do not add comments to code.
- Never format generated files or build/cache directories.
- Prefer explicit imports; do not introduce star imports. ktfmt does not expand
  existing star imports, so follow this rule when adding or optimizing imports.

# Source control

- Commit as you go. After completing a coherent change and running the relevant
  checks, create a focused commit before moving on to unrelated work.
- Stage only changes that belong to the current task. Preserve unrelated work.
- Follow the [source control guide](docs/source-control.md) for commit scope,
  review, and validation.
